# Changelog

## [0.2.0] - 2026-09-26

### Добавлено
- Сравнение двух срезов (A/B): второй плейхед B (Alt+клик по линейке, клавиша B, кнопка «A/B»), панель изменений A → B в срезе.
- Сейвы по контрольным точкам для QA: начало каждого акта + трек «Контрольные точки», `manifest.json` со списком.
- Телеметрия плейтестов: импорт CSV/JSON в ассет `TelemetryData`, наложение «план против факта» на треки
  (точки сессий, медиана, половина игроков), отклонения в Inspector.
- Обмен с таблицами: экспорт/импорт CSV (элементы, ключи кривых, простые поля любых типов, привязки по пути ассета)
  и JSON всего ассета. Импорт отменяется через Undo.
- Версии ассета: сохранение снимков, сравнение с версией — список изменений и «призраки» прежних позиций на таймлайне.
- Runtime API: `ProgressionDiff`, `TimelineDiff`, `Checkpoints`, `TelemetryIndex`, `TelemetryImport`, `Csv`.

## [0.1.0] - 2026-09-26

Первый выпуск. Лицензия MIT.

### Добавлено
- Окно *Progression Timeline* на UI Toolkit: линейка, плейхед, зум (слайдер, Ctrl+колесо), снэп, проигрывание.
- Треки: Фабула, Сюжет, Прокачка, Локации, Апгрейды, Прогресс (кривая уровня); базовые клипы, маркеры, кривые.
- Редактирование: перенос, изменение начала и длительности за края клипа, ключи кривой по обеим осям,
  мультивыделение (Ctrl+клик, рамка), копирование / вставка / дублирование / удаление, сворачивание и порядок треков, Undo.
- Inspector на PropertyField: поля любых типов треков и элементов, требования, нарушения, превью привязанного ассета.
- Срез игры из пяти карточек; `IProgressionQuery.Evaluate(t) → ProgressionState`.
- Проверка зависимостей: авто и ручной режим (EditorPrefs), подсветка, бейдж, отчёт в Inspector и Console.
- Сейвы: `ISaveBuilder` (встроенный JSON), настройки в *Project Settings → TimeMapGameplay*, «Создать сейв», «Play Mode с t»,
  `ITimelineBootstrap`, `TimelineLaunch`.
- Точки расширения с автообнаружением: `IValidationRule`, `Requirement`, `ISlicePanel` + `[SlicePanel]`,
  `TrackDrawer` + `[CustomTrackDrawer]`, `IPreviewSource`, `[TrackMenu]`.
- Тёмная и светлая темы редактора.
- Сэмплы: RPG Campaign, Metroidvania.
