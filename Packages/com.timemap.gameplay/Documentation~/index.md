# Руководство дизайнера

## Понятия

- **Ось времени** — время игры, а не секунды сцены. Единицы: часы, сессии или номер квеста (Inspector без выделения).
- **Фабула** — события мира. Клип стоит там, где игрок *узнаёт* событие; `Chrono Index` — место события в истории мира.
- **Сюжет** — порядок подачи: акты, главы, квесты.
- **Срез игры** — состояние всех треков в момент плейхеда.

## Окно

| Область | Что делает |
|---|---|
| Тулбар | Play/Pause, время, зум, снэп, «Play Mode с t», «Создать сейв», «Проверить», «авто», бейдж нарушений, выбор ассета |
| Срез игры | Карточки Акт, Герой, Карта мира, Фабула, Снаряжение (+ карточки проекта) |
| Таймлайн | Заголовки треков, линейка (клик/перетаскивание — плейхед), дорожки |
| Inspector | Выделенный элемент / группа / трек; без выделения — настройки оси и отчёт проверки |

Размеры областей меняются перетаскиванием разделителей.

## Мышь

- Перетаскивание элемента — перенос (всей выделенной группы). **Shift** — без привязки к снэпу.
- Левый край клипа — начало (конец на месте), правый — длительность.
- Ключ кривой — по времени и значению.
- **Ctrl+клик** — добавить/убрать из выделения. Рамка по пустому месту — выделение.
- **ПКМ** по дорожке — добавить элемент / вставить; по элементу — копировать, дублировать, удалить;
  по заголовку трека — свернуть, порядок, удалить; по кривой — добавить ключ.
- «+ Трек» в левом верхнем углу — новый трек.
- **Ctrl+колесо** — зум вокруг курсора.

## Клавиши

| Клавиша | Действие |
|---|---|
| Space | проигрывание |
| ← / → | плейхед на шаг снэпа |
| Home / End | в начало / в конец |
| Alt+← / → | сдвиг выделенного |
| Esc | снять выделение |
| Ctrl+C / X / V / D / A, Delete | копировать, вырезать, вставить (в плейхед), дублировать, выделить всё, удалить |

## Требования и проверка

У любого элемента в Inspector есть секция «Требования»: открытая локация, раскрытый факт фабулы, уровень героя
(и типы, добавленные проектом). Навыки и апгрейды дополнительно проверяются по своему `Min Level` и кривой уровня.

- **авто** — проверка после каждого изменения;
- ручной режим — только по «Проверить»; после изменений бейдж показывает «не проверено», старые пометки остаются.

Клик по бейджу переходит к первому нарушению; строки отчёта в Inspector кликабельны. «Проверить» пишет отчёт в Console.

## Сейвы и Play Mode с t

«Создать сейв» записывает состояние в момент плейхеда в папку из *Project Settings → TimeMapGameplay*.
«Play Mode с t» пишет временный сейв и запускает игру; как игра его загрузит — см. [Интеграцию](Integration.md).

## Анализ

Всё ниже — в кнопке **Ещё** на тулбаре и в Inspector без выделения (секция «Анализ»).

### Сравнение двух срезов (A/B)

Кнопка **A/B** включает второй плейхед B. Поставить B: **Alt+клик/перетаскивание** по линейке или клавиша **B**
(B встаёт на место плейхеда A). Над карточками появляется панель: что игрок получит (или потеряет) между A и B —
акт, навыки, локации, снаряжение, фабула, уровень.

### Сейвы по контрольным точкам

**Ещё → Сейвы по контрольным точкам** пишет по сейву на начало каждого акта и на каждый маркер трека
«Контрольные точки» (+ Трек). Рядом кладётся `manifest.json` со списком: номер, имя, время, файл — для QA.

### Телеметрия: план против факта

1. Выгрузите из плейтестов CSV с колонками `session, item, time` (или JSON). `item` — id элемента, его имя
   или GUID привязанного ассета; `time` — время в единицах оси (`3.5` или `3:30`).
2. **Ещё → Телеметрия → Импорт** — файл превращается в ассет `TelemetryData`.
3. На треках под элементами появятся точки сессий, полоса «половина игроков» и медиана.
   Оранжевая линия — игроки приходят позже плана, синяя — раньше. Подробности — в подсказке элемента и в Inspector.

### Таблицы (CSV / JSON)

**Ещё → Таблица → Экспорт CSV** — строка на элемент (и на ключ кривой), колонки: трек, тип, id, имя, начало,
длительность, значение, путь привязанного ассета и все простые поля элемента (`minLevel`, `slot`, `chronoIndex`…).
Правьте в Google Sheets / Excel и импортируйте обратно: элементы находятся по `id`, строки без `id` создают новые
элементы на треке из колонки `track`. Удалённые из таблицы строки в таймлайне **не** удаляются. Импорт отменяется Undo.
JSON — полная копия ассета (для бэкапа и внешних инструментов).

### Версии

**Ещё → Версии → Сохранить версию** кладёт копию в папку `<Имя>_Versions` рядом с ассетом.
**Сравнить с последней** (или выбрать версию в Inspector): список изменений в Inspector (клик — к элементу),
а сдвинутые и удалённые элементы видны на таймлайне пунктиром на прежнем месте.
