# TimeMapGameplay

Инструмент геймдизайнера в Unity Editor: прогрессия игры на таймлайне в стиле видеоредактора и «срез игры» в любой момент времени.

- Треки фабулы, сюжета, прокачки, локаций, апгрейдов и кривая уровня на одной оси времени игры (часы, сессии или квесты).
- Срез игры над таймлайном: акт, герой, карта мира, фабула, снаряжение — пересчитывается при движении плейхеда.
- Проверка зависимостей (авто или по кнопке): акт требует локацию, навык — уровень, квест — факт фабулы, битые ссылки.
- «Создать сейв» и «Play Mode с t» через сменные адаптеры формата сейва.
- Расширяется без правки пакета: свои треки, требования, правила, карточки среза, превью ассетов, форматы сейва.

**Требования:** Unity 6000.3 или новее.

## Установка

Через Package Manager → *Add package from git URL*:

```
<URL репозитория>.git?path=/Packages/com.timemap.gameplay
```

Или скопируйте папку `com.timemap.gameplay` в `Packages/` проекта.

## Быстрый старт

1. *Window → TimeMapGameplay → Progression Timeline*.
2. *Tools → TimeMapGameplay → Create Demo Timeline* — или импортируйте сэмпл *RPG Campaign* / *Metroidvania* в Package Manager.
3. Двойной клик по ассету `ProgressionTimeline` открывает его в окне.
