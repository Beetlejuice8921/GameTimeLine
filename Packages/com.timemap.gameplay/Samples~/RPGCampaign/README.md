# RPG Campaign

Кампания на 20 часов игры: фабула, четыре акта, навыки, локации, снаряжение и кривая уровня.

Что показывает:

- **Привязка к ассетам проекта.** Акты привязаны к `QuestAsset`. Поля квеста `title` / `description` / `icon`
  подхватываются превью без кода адаптера: см. Inspector акта и карточку «Акт».
- **Свой формат сейва.** `RpgSaveBuilder` превращает `ProgressionState` в `RpgSave` (формат «игры»).
  Выберите «RPG sample save» в *Project Settings → TimeMapGameplay*, затем «Создать сейв» или «Play Mode с t».
- **Загрузка при Play Mode с t.** `RpgBootstrap` читает сейв до загрузки первой сцены и кладёт его в `RpgGameState.Current`.
- **Своё правило проверки.** `ActQuestBindingRule`: акт, привязанный не к `QuestAsset`, даёт предупреждение.
- **Телеметрия.** `Playtest_Telemetry.csv` — 8 выдуманных плейтестов (трое не дошли до финала).
  *Ещё → Телеметрия → Импорт*, затем смотрите на треки: игроки в среднем отстают от плана.
- **Нарушение в данных.** Акт III требует Крепость, которая открывается на полчаса позже начала акта.

Откройте `RPGCampaign.asset` двойным кликом.
