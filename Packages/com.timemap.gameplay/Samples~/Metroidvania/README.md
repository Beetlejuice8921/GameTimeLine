# Metroidvania

Замок на 12 игровых сессий: главы, способности перемещения, зоны, боссы, реликвии и сила героини. Ось — в сессиях.

Что показывает:

- **Свои типы треков.** `AbilityTrack` и `BossTrack` (с полями `Unlocks`, `HitPoints`, `Reward`) — появляются в «+ Трек»,
  их поля — в Inspector без кода редактора.
- **Свой тип требования.** `AbilityRequirement`: зона требует способность. Доступен в «+ Требование», проверяется валидатором.
- **Свой отрисовщик трека.** `BossTrackDrawer` показывает HP рядом с именем босса.
- **Своя карточка среза.** `BossesPanel` («Боссы») — побеждённые и следующий босс; скрыта у таймлайнов без трека боссов.
- **Нарушение в данных.** Подводный храм открывается в сессии 7, а «Ныряние», без которого туда не попасть, — только в 8.

Откройте `Metroidvania.asset` двойным кликом.
